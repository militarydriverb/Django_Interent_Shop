# Это проект интернет-магазина
## Данный проект будет дорабатываться от урока к уроку.

## Настройка проекта
1. Создаем директорию проекта
2. Инициализируем новый проект Django внутри этой директории.
Добавляем в файл .gitignore и правила ведения разработки по GitFlow. 
Создаем ветки main develop и отдельные ветки для решения домашек. 
Оформляем файл README с описанием проекта.

## Создание и настройка приложения
1. Создаем новое приложение под названием catalog в вашем проекте.
2. Регистрируем приложение в настройках проекта.
3. Настраиваем маршрутизацию для нового приложения, добавив соответствующие URL-адреса.

## Создание шаблонов
1. Готовим два HTML-шаблона: для домашней страницы и для страницы с контактной информацией.
2. Для стилизации страниц используем Bootstrap.

## Реализация контроллеров
1. Создаем контроллер для отображения домашней страницы.
2. Создаем контроллер для отображения страницы с контактной информацией.
3. Настраиваем маршрутизацию для этих контроллеров.

## Реализация формы обратной связи
1. Реализуем форму обратной связи на странице контактов.
2. Настраиваем обработку данных формы в контроллере, чтобы отображать сообщение об успешной отправке данных.
